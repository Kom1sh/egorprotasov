# egorprotasov.ru

Личный сайт. Статика на GitHub Pages, страницы собирает свой генератор на Python без зависимостей.

## Сборка

```sh
python3 build.py          # страницы, картинки, sitemap, llms.txt, проверки
python3 build.py --og     # плюс превью для соцсетей и иконки (нужен Google Chrome)
```

Нужны Python 3.11+, `sips` (есть в macOS) и `cwebp` (`brew install webp`). Результат пишется в корень репозитория: его и отдаёт GitHub Pages.

## Где что лежит

| Путь | Что там |
|---|---|
| `src/site.toml` | главная: представление, путь, «Вне работы», контакты |
| `src/projects/*.toml` | страницы проектов, по файлу на проект |
| `src/data/*.csv` | ряды для графиков |
| `src/img/` | исходные фото, генератор режет их в `assets/img/` |
| `sitegen/` | генератор: типографика, графики, страницы, проверки |
| `assets/site.css`, `assets/chart.js` | стили и курсор для графиков |

В текстах работают `[ссылка](адрес)` и `**выделение**`. Предлоги, числа и слова через дефис переносятся по правилам русской вёрстки автоматически.

## Как обновить цифры

1. Выгрузить свежие данные в `src/data/*.csv`: визиты из поиска — из Яндекс.Метрики, клики и показы — из Search Console.
2. Поправить тексты с цифрами в `src/projects/*.toml`, дату в `src/site.toml` (`meta.updated`) и `ASOF` в `build.py`.
3. `python3 build.py --og`, проверить локально: `python3 -m http.server 8765`.

## Проверки при сборке

- **Запрещённые слова.** Названия и домены клиентов, название агентства. Список хранится только в виде хешей в `sitegen/guard.py`, чтобы сам он не лежал в публичном репозитории. Если слово попало на страницу или в исходники, сборка останавливается.
- **Приметы сгенерированного текста.** Разделитель «·», стрелки, конструкции «не …, а …», «ровно». Это предупреждения, сборка не падает.

Клиентские проекты на сайте только обезличенные. Сырые выгрузки Search Console в репозиторий не кладутся, только сглаженные ряды, которые и так видны на графиках.
